# 八正道（はっしょうどう）の教え

釈尊が初転法輪（鹿野苑での最初の説法）で説いた、苦を滅するための八つの正しい道。四諦のうち「道諦」に相当する実践綱領である。

## 四諦との関係

- **苦諦** … 人生には苦があるという真理
- **集諦** … 苦の原因は渇愛（欲望・執着）であるという真理
- **滅諦** … 苦は滅することができるという真理
- **道諦** … 苦を滅する道が八正道であるという真理

## 八正道の内容

「正」は「真理にかなった・調和のとれた」という意味。自己本位ではなく、縁起や中道の視点で見る・考える・行動することを示す。

| 項目 | 内容 |
|------|------|
| **正見**（しょうけん） | 自己中心的な見方ではなく、中道の見方をする。誤った見解を離れ、因果や縁起を正しく見る。 |
| **正思**（しょうし） | 真理に照らし合わせて物事を考える。貪り・怒り・害の心を離れ、出離・無瞋・無害の心を養う。 |
| **正語**（しょうご） | 真理にかなった言葉を使う。妄語・両舌・悪口・綺語を避け、誠実で調和のある言葉を話す。 |
| **正業**（しょうごう） | 仏の戒めにかなった行いをする。殺生・盗み・邪淫を離れ、正しい身業を保つ。 |
| **正命**（しょうみょう） | 正しい職業で得た収入で生活する。欺きや害を伴う生業を避ける。 |
| **正精進**（しょうしょうじん） | 与えられた使命や目的に対して正しく励む。悪を断ち善を修めるよう努める。 |
| **正念**（しょうねん） | 真理に向いた正しい心を保つ。身体・感受・心・法を忘れずに観察する（念）。 |
| **正定**（しょうじょう） | 真理に照らし、正しい状態で心を定める。禅定によって心を乱れなき状態に置く。 |

## 説話での活用のヒント

- 主人公が「正見」を得るまでに、師や出来事を通じて誤った見方が揺らぐ場面を描ける。
- 「正語」「正業」を破った結果としての苦と、それを改めた後の変化を対比できる。
- 「正命」— 生業の選び方や、不正な商いから足を洗う話に結びつけやすい。
- 「正念」「正定」— 瞑想・修行の場面で、心の静けさや気づきとして描ける。
