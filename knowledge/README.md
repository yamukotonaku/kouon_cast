# 仏教の知識（knowledge/）

このフォルダには、説話生成時にプロンプトとして渡す**仏教の知識**を Markdown（.md）で置きます。

- **stories/** … 既存の説話テキスト（説話のトーン・文体の参考）
- **knowledge/** … 仏教の教義・用語・故事などの知識（説話に深みを出すための参考）

## 使い方

1. このフォルダに `.md` ファイルを追加する。
2. 説話を生成すると、`stories/` の説話集とあわせて `knowledge/` 内の Markdown が読み込まれ、Gemini のプロンプトに「【仏教の知識（参考・活用すること）】」として渡される。
3. ファイル名のアルファベット順で結合される。必要に応じて先頭に数字をつける（例: `01_四諦.md`, `02_八正道.md`）。

## 記載例

- 四諦・八正道・六波羅蜜などの教義の要約
- 仏教用語の簡潔な説明（縁起、無常、慈悲、忍辱など）
- ブッダや弟子にまつわる短いエピソード・故事
- 説話の舞台になりうる地域・時代の背景メモ

説話の「冒頭を切り貼りしただけ」にならないよう、**知識として整理した説明**を書いておくと、モデルが教養を活かした物語を組み立てやすくなります。
