# **原始仏教における理論的基盤とその構造的特質：初期仏典に基づく存在論および実践論の学際的考察**

## **原始仏教の定義と学術的時代区分における位置付け**

原始仏教（Early Buddhism）は、ゴータマ・ブッダ（釈尊）の活動期から、仏教教団が上座部と大衆部に根本分裂を遂げるまでの約100年から150年間を指す学術的な時代区分である 1。この時期は、教理が固定的なドグマ（教条）としてアビダルマ（阿毘達磨）化される以前の、柔軟かつ実践的な教育体系が維持されていた時代として定義される 1。学術研究の文脈において、原始仏教という呼称は釈尊の直接の教えという「オリジナル」の純粋性に重きを置く場合に用いられ、一方で「初期仏教」という呼称は、大乗仏教などの後世の展開と比較して「時代的に早い段階」であることを強調する際に好まれる傾向がある 1。

原始仏教の理論を解明するための主要な資料は、パーリ語で伝承された「五部（ニカーヤ）」および漢訳された「阿含経（アガマ）」であり、これらは仏教思想の最古層を形成している 2。これらの文献が示す思想的特徴は、形而上学的な宇宙論や絶対者の設定を排除し、徹底して人間の「苦（ドゥッカ）」という現実に立脚した実践的仮説を提示している点にある 3。このため、原始仏教は宗教という枠組みを超え、一種の心理学的、あるいは医学的な治療プロセスとしての性質を強く帯びている 3。

## **四聖諦：苦の解消に向けた因果モデルのシステム化**

釈尊が成道（悟り）の後に最初に行った説法、いわゆる「初転法輪（しょてんぽうりん）」において提示されたのが、四聖諦（ししょうたい）である 3。これは「四つの聖なる真理」を意味し、初期仏教の教理体系において最も根本的な因果モデルとして機能している 3。

### **四聖諦の論理構造と医学的診断プロセス**

四聖諦の構造は、現状分析（苦）、原因の特定（集）、理想状態の提示（滅）、および達成手段の提示（道）という四段階で構成されており、これは当時のインドにおける医学的診断、すなわち「病、病因、健康（平癒）、治療法」というプロセスと軌を一にしている 3。

| 聖諦の名称 | 理論的定義 | システム上の役割 |
| :---- | :---- | :---- |
| 苦諦 (Dukkha-satya) | 生存は本質的に「思い通りにならない（苦）」という真実。 | 現状の分析（結果の提示） |
| 集諦 (Samudaya-satya) | 苦の原因は「渇愛（渇望）」であるという真実。 | 原因の特定（因の解明） |
| 滅諦 (Nirodha-satya) | 原因を滅すれば、苦も消滅（涅槃）するという真実。 | 理想の提示（結果の消滅） |
| 道諦 (Magga-satya) | 苦の消滅に至るための具体的実践（八正道）という真実。 | 手段の提示（因の除去） |

3

この体系は、単なる信念の告白ではなく、「苦は原因なくしては生じない。原因が滅すれば、苦もまた必ず滅する」という徹底した科学的因果律に支えられている 3。初期仏教において「諦（真理）」とは、人間の経験に即した実証的な法則性を意味しており、宇宙の絶対法則を語るものではないという点が重要である 3。

### **苦諦の多層的分析：四苦八苦と五取蘊**

苦諦において示される「苦（ドゥッカ）」とは、感覚的な苦痛のみならず、「自分の思い通りにならないこと」を本質とする 4。原始仏教ではこれを、日常的な「四苦八苦」という概念を用いて具体化している 6。

1. **基本的四苦**: 生（誕生に伴う制約）、老（老化による衰え）、病（病気による苦痛）、死（死への恐怖と消滅）。これらは生存そのものに付随する不可避的な現象とされる 6。
2. **社会的・心理的四苦**:
   * 愛別離苦（愛するものと別離しなければならない苦しみ）
   * 怨憎会苦（憎むものと会わなければならない苦しみ）
   * 求不得苦（求めるものが得られない苦しみ） 6。
3. **存在論的苦**: 五蘊盛苦（五つの構成要素への執着そのものが苦である）。

特に「五蘊盛苦」あるいは「五取蘊（ごしゅうん）」が苦であるという定義は、原始仏教の存在論と直結している 6。これは、人間を構成する五つの要素（五蘊）を「自己」であると見なして執着すること自体が、苦しみの根本的な要因であることを示している 6。

### **集諦と渇愛のメカニズム**

集諦では、苦の原因を「渇愛（かつあい、タンハー）」に求める。我々は現実に満足せず、常に「こうあってほしい」という欲望、あるいは「こうあってほしくない」という嫌悪の心（煩悩）を抱えている 5。

渇愛は以下の三種に分類される：

* **欲愛**: 感覚的な喜び（五欲）を追い求める渇望。
* **有愛**: 自分が存在し続けたい、永遠でありたいという生存への執着。
* **無有愛**: 逆に、今の自分や状況を否定し、無きものにしたいという虚無的な渇望 6。

これらの渇愛が満たされないとき、あるいは満たされたものが崩壊するときに苦が生じる 5。したがって、苦を解決するためには、外的な要因を操作するのではなく、内的な要因である「渇愛」そのものを消滅させる必要があるとされる 6。

## **存在論の基礎：五蘊説による自己の解体**

原始仏教における存在論（世界および自己の捉え方）の核心は、固定的な「実体」としての自我を否定し、すべての存在を機能的な「要素の集積」として分析する点にある。この分析手法の基本単位が「五蘊（ごうん、panca-skandha）」である 8。

### **五蘊の構成と精神物理的プロセス**

五蘊は、人間の存在およびその精神作用を、物質的な側面と精神的な側面の五つのグループに分類したものである 8。

| 五蘊の名称 | 定義と機能 | 精神作用における役割 |
| :---- | :---- | :---- |
| 色蘊 (Rupa) | 肉体および物質。外部刺激を受け、また物理的に傷つく性質を持つ。 | 物理的基盤・感覚器官。 8 |
| 受蘊 (Vedana) | 感受作用。対象に対して「苦・楽・不苦不楽」の感情を抱く。 | 刺激に対する原初的な反応。 8 |
| 想蘊 (Sanna) | 表象作用。対象が「何であるか」を概念的に捉え、名称を付ける。 | 識別とラベリング。 8 |
| 行蘊 (Sankhara) | 形成作用。意志、衝動、無意識の動機など、心を作動させる。 | 行動の動機付け・意志の形成。 8 |
| 識蘊 (Vinnana) | 認識作用。六つの感覚（眼耳鼻舌身意）を通じて対象を識別する。 | 統合的な認識の確立。 8 |

精神作用のプロセスとして見ると、まず「色（対象）」を「受（感受）」し、「想（概念化）」することで「行（意志）」が働き、最終的に「識（判断）」に至る 10。この中で「行」は無意識的な意志の形成過程を含んでおり、これが後の「業（カルマ）」の形成に深く関与する 10。

### **諸法無我と「コントロール」の視点**

釈尊は、これらの五蘊のいずれもが「自分（我）」ではないと説いた（諸法無我） 8。その論理的な根拠として示されたのが「コントロールの不可能性」である 10。

もし「肉体（色）」や「感覚（受）」が自分自身であるならば、我々はそれらに対して「病気になるな」「常に快楽であれ」と命じ、その通りにコントロールできるはずである 10。しかし現実はそうではない。肉体は老い、病み、感覚は不本意な苦痛をもたらす。この「思い通りにならない（無我）」という事実は、五蘊が不変の主体ではなく、因縁によって生じている現象に過ぎないことを証明している 10。

したがって、原始仏教における無我とは、「魂が存在するか否か」という抽象的な議論ではなく、「自分のものであると執着している心身の諸要素は、実は自分ではコントロールできない仮の集積である」という事実認識を指している 9。

## **縁起説：存在と認識の動的な因果律**

原始仏教において、四聖諦と並んで重要な理論的支柱が「縁起（えんぎ、パティッチャ・サムッパーダ）」である 11。これは「すべての物事は、直接的・間接的な原因（因縁）が和合して生じ、原因がなくなれば滅する」という相互依存的な法則を意味する 8。

### **縁起の論理構造と歴史的発展**

縁起説は、最初から「十二支縁起」として完成していたわけではなく、初期仏典の中ではいくつかの発展段階が確認できる 2。

1. **三事和合説**: 最も初期的な形態であり、認識の成立を説明する。「眼（器官）＋色（対象）＋眼識（意識）」の三つが和合したときに「触（接触）」が生じるという構造である 2。
2. **十支縁起説**: 「識」と「名色（精神的・物質的要素）」の相互依存関係を中心とする。識は名色を拠点として増長し、名色も識によって維持されるという、胎生学的・生命的な循環を説明する 2。
3. **十二支縁起説**: 十支縁起に「無明（むみょう）」と「行（ぎょう）」という遡及的な原因を加え、苦しみの生起プロセスを体系化した完成形である 2。

### **十二支縁起の連鎖**

十二支縁起は、苦しみがどのように生起するか（流転門）、そしてどのように滅尽するか（還滅門）を詳細に記述している 3。

| 支分の名称 | 理論的意義 |
| :---- | :---- |
| 無明 (Avidya) | 真理（四聖諦・縁起）に対する無知。すべての苦の根源。 |
| 行 (Samskara) | 無明に基づく潜在的な形成力、意志の働き。 |
| 識 (Vijnana) | 認識の主体。再生的生存の契機となる意識。 |
| 名色 (Nama-rupa) | 精神的（名）および物質的（色）な存在の基本形。 |
| 六処 (Sad-ayatana) | 六つの感覚器官（眼・耳・鼻・舌・身・意）。 |
| 触 (Sparsa) | 器官と対象と意識の接触。 |
| 受 (Vedana) | 接触から生じる感受作用。 |
| 愛 (Trsna) | 感受に対する激しい渇望（渇愛）。 |
| 取 (Upadana) | 渇愛に基づく執着、捉えて離さないこと。 |
| 有 (Bhava) | 執着によって形成された生存の状態。 |
| 生 (Jati) | 新たな生存、誕生。 |
| 老死 (Jara-marana) | 老い、死、およびそれに伴う憂悲苦悩。 |

2

この連鎖において、第一原因である「無明」が「正見（正しい智慧）」によって滅せられれば、連鎖的にすべての支分が停止し、最終的に「老死」という苦が滅する（還滅）ことが論理的に帰結される 3。

## **実践論としての中道と八正道**

理論としての四聖諦や縁起を、具体的にどのように生活や修行に落とし込むかを示すのが「中道（ちゅうどう）」および「八正道（はっしょうどう）」である 11。

### **中道：両極端の回避と合理的平衡**

中道とは、釈尊が成道前に経験した「快楽への耽溺」と「過酷な苦行」の両極端を否定した結果として見出された実践的指針である 4。

* **苦楽の中道**: 肉体を痛めつける極端な苦行は知性を鈍らせ、感覚的な快楽に耽ることは煩悩を増長させる。したがって、そのいずれにも偏らない「理にかなった道」を歩むべきとされる 11。
* **存在論的中道**: 中道はまた、思想的な極端、すなわち「常見（永遠に変わらない実体があるとする）」と「断見（死ねばすべてが無になるとする）」の両方を、縁起の真理に基づいて否定する 9。

中道は、単なる二つの間の妥協点ではなく、世界のありのままの姿（縁起）を正しく洞察するための最も効率的かつ積極的な「智慧の道」として定義される 11。

### **八正道の具体的実践**

道諦において示される「八正道」は、中道の具体的な内容を八つの項目に整理したものである 6。

1. **正見**: 真理（四諦・縁起）を正しく理解すること。
2. **正思惟**: 正しい考え方、貪欲や怒りを離れた思考。
3. **正語**: 正しい言葉、虚偽や悪口を言わないこと。
4. **正業**: 正しい行為、殺生や盗みを行わないこと。
5. **正命**: 正しい生活、道徳的な職業と規則正しい暮らし。
6. **正精進**: 正しい努力、悪を捨て善を養う持続的な励み。
7. **正念**: 正しい気づき、自分の身心の状態を常に客観的に観察すること。
8. **正定**: 正しい集中、瞑想（禅定）による心の安定 6。

これらは、現代の心理学的アプローチにおける「認知変容（正見・正思惟）」「行動変容（正語・正業・正命）」「心理訓練（正精進・正念・正定）」の統合系として捉えることも可能である 8。

## **解脱への階梯：四向四果と煩悩の断絶**

原始仏教における修行の目的は、心身を束縛する煩悩を断じ、輪廻の苦から解放される「解脱（げだつ）」および「涅槃（ねはん）」に至ることである 7。この達成度合いに応じて、修行者は「四向四果（しこうしか）」という八段階の聖者に分類される 12。

### **聖者の四段階と断じるべき煩悩（結）**

修行者は、下級の五つの束縛（五下分結）と、上級の五つの束縛（五上分結）を順に断滅していく 12。

| 聖者の階位 | 断じるべき主な煩悩（結） | 特徴と最終的帰結 |
| :---- | :---- | :---- |
| 預流 (須陀含) | 有身見（自我への執着）、疑（真理への疑い）、戒禁取（誤った戒律）。 | 聖者の流れに入り、最大7回以内の転生で覚る。 12 |
| 一来 (斯陀含) | 預流の三結に加え、欲界の貪欲と瞋恚を大幅に弱める。 | 天界と人間界を一回だけ往来して覚る。 12 |
| 不還 (阿那含) | 五下分結（有身見・疑・戒禁取・貪欲・瞋恚）を完全に断つ。 | 欲界には戻らず、色界の浄居天で涅槃に入る。 12 |
| 阿羅漢 (応供) | 五上分結（色貪・無色貪・慢・掉挙・無明）を完全に断つ。 | 究極の悟り。一切の煩悩（漏）を滅した最高位。 12 |

阿羅漢は、人々からの供養に値する尊い存在（応供）とされ、もはや学ぶべきことがない「無学（むがく）」の境地に達した者とされる 12。

### **涅槃の定義と性質**

解脱の境地である「涅槃（ニルヴァーナ）」は、語源的には「吹き消すこと」を意味し、渇愛という火が消え、苦しみが停止した状態を指す 7。これは死後の状態を指すだけでなく、生存中であっても煩悩が滅していれば、それを「有余涅槃（うよねはん）」と呼んで高く評価する。涅槃は「一切の形成作用（行）の静止」であり、執着による束縛から完全に解放された「真の安らぎ」であるとされる 6。

## **原始仏教と大乗仏教の思想的連続性と差異**

仏教の理論的発展を考える上で、原始仏教の思想がいかに大乗仏教へと変容、あるいは継承されたかを理解することは重要である。

### **阿羅漢（声聞）から菩薩への転換**

原始・部派仏教における理想像が「阿羅漢」であったのに対し、大乗仏教は「菩薩（ぼさつ）」という新たな理想像を掲げた 17。

* **阿羅漢（声聞）の性格**: 釈尊の教えを聞いて修行し、自己の解脱（自利）を目的とする。大乗の側からは「利他の慈悲が不足している」と批判された 17。
* **菩薩の性格**: 釈尊が悟りを開く前の修行時代（ジャータカに語られる本生話）をモデルとし、自らも仏（ブッダ）になることを目指し、一切の衆生を救う「利他」を不可分とする 17。

### **「無我」から「空」へ**

原始仏教の「諸法無我（実体的な自己の否定）」という論理は、後に大乗仏教において「空（くう）」という概念へと深化・拡張された。原始仏教では五蘊という要素（法）の実体性は必ずしも明確に否定されていなかったが、大乗仏教は「般若経」などを通じ、五蘊そのものもまた実体のない「空」であると説くに至った。これは原始仏教の縁起説（相互依存性）を徹底的に論理化した帰結と言える 11。

## **結論：初期仏教理論の現代的有用性と学術的価値**

原始仏教の理論体系は、徹底して「苦しみの現実」を直視し、それを合理的に分析して解消を目指すという極めて知的な性格を持っている 3。その中核となる四聖諦、五蘊、縁起の諸説は、単なる宗教的信念ではなく、人間の認知と存在の構造を解き明かす「実践的仮説」として、現代の心理学や哲学の領域においてもなお深い洞察を提供し続けている 3。

釈尊が提示した「中道」の歩みは、固定的なドグマや感情的な極端に走ることなく、事象を「あるがまま（如実）」に捉える智慧の獲得を促す 10。この「自己の解体と再構築」という理論的プロセスこそが、原始仏教が2500年以上にわたって多様な文化圏で受容され、今なお普遍的な説得力を持ち続ける源泉であると結論づけられる。
